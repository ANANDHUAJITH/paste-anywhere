GOOD TO KNOW

Frequently asked questions

Are my files uploaded or stored?

No. File data is sent over the peer-to-peer WebRTC connection and held in browser memory during transfer. The website does not provide file storage.

Do both devices need the same room details?

Yes. Enter the exact same username and password on both devices. Use a unique, hard-to-guess pair and do not reuse an important password.

Why might a device fail to connect?

Some VPNs, restrictive firewalls, mobile networks and NAT configurations block direct peer connections. This version uses STUN but has no TURN relay fallback, so it may not work on every network.

Can I use it on a phone and a computer?

Yes, use a modern browser on both devices. Keep both browser tabs open while syncing text or transferring files.
