GOOD TO KNOW

Frequently asked questions

Are my files uploaded or stored?

No. File data is sent over the peer-to-peer WebRTC connection and held in browser memory during transfer. The website does not provide file storage.

How many devices can join the same room?

Any number. Enter the exact same username and password on every device — the first one creates the room, and every device after that automatically joins it. Everyone sees the same live text and receives every file that's sent.

Can someone else create a new room with my username and password?

No. While a room is active, its username & password are reserved for that room — trying to "create" a new room with the same pair just joins the existing one instead of starting a separate one. Once everyone disconnects and the room closes, the same pair is free to be used again (by you or anyone else), so pick a pair that isn't easy to guess.

Why might a device fail to connect?

Some VPNs, restrictive firewalls, mobile networks and NAT configurations block direct peer connections. This version uses STUN but has no TURN relay fallback, so it may not work on every network.

Can I use it on a phone and a computer?

Yes, use a modern browser on each device. Keep every browser tab open while syncing text or transferring files.
